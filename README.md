# 📋 Kanban Board

A simple and interactive **Kanban Board** built using HTML, CSS, and JavaScript. It provides a visual way to organize tasks into different stages of completion, making task management easier and more organized.

## ✨ Features

- **Three Task Columns:** Organize tasks into To Do, In Progress, and Done.
- **Task Counter:** Display the total number of tasks.
- **Column Counters:** Show the number of tasks in each column.
- **Add a Task:** Includes a button to open the task creation interface.
- **Task Details:** Input fields for a task title and description.
- **Theme Toggle:** A button to switch between Light and Dark themes.
- **Modal Interface:** A task creation form with a close button.
- **Responsive Layout:** Designed with a viewport meta tag to support different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Structures the Kanban board and task form.
- **CSS3** — Styles the layout, columns, buttons, and modal.
- **JavaScript** — Adds interactivity and manages task-related functionality.

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Download or clone the repository.
2. Open the project folder in your code editor.
3. Make sure `index.html`, `index.css`, and `index.js` are in the same directory.
4. Open `index.html` in your web browser.
5. Use the Kanban Board interface to manage your tasks.

## 📖 How to Use

1. Open the Kanban Board in your browser.
2. Click **Add a Task** to access the task creation form.
3. Enter a task title and description.
4. Click **Add Task** to submit the task.
5. Organize tasks under To Do, In Progress, or Done, depending on the functionality implemented in JavaScript.
6. Use the theme button to switch themes if the feature is implemented.

## 🎯 Project Purpose

The purpose of this project is to build a simple task management interface and practice front-end web development concepts, including HTML structure, CSS styling, DOM manipulation, and JavaScript event handling.
